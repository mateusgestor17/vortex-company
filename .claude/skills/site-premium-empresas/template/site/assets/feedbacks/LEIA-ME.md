# Feedbacks de clientes

Coloque aqui as imagens (prints) de feedbacks dos clientes — `.jpg`, `.png` ou `.webp`.

Depois, liste cada imagem em `assets/js/data.js`, no campo `feedbacks`:

```js
feedbacks: [
  { src: "assets/feedbacks/cliente-01.jpg", alt: "Descrição da imagem", destaque: "Frase curta exibida abaixo do print" },
],
```

A galeria aparece automaticamente no site quando houver pelo menos uma imagem listada.
